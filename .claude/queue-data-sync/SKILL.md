# Queue Data Sync Skill

## Usage

- Create job classes in `app/Jobs/`
- Dispatch jobs from controllers or events.
- Configure queue driver (database, redis).
- Monitor with Laravel Horizon if needed.

## Goals

- Handle heavy operations asynchronously.
- Improve app performance and responsiveness.
