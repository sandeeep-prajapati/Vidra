# Subject Management

Define the **academic curriculum** — subjects, class-subject assignments, curriculum plans, textbooks, and teacher-subject mappings — all in one connected module.

---

## Features

- **Subjects** — create subject records with type
- **Class-Subject Assignments** — assign subjects to classes
- **Curriculum** — link subjects to academic years
- **Textbooks** — add textbooks per subject
- **Teacher-Subject Mappings** — assign qualified teachers to subjects

---

## Subjects

Navigate to `/subjects` to see all subjects.

### Create a Subject

1. Click **Add Subject**
2. Fill in:
   - **Subject Name** — e.g. `Documentation Science`
   - **Subject Code** — short code (e.g. `SCI-001`)
   - **Subject Type** — `Theory`, `Practical`, or `Lab`
3. Click **Create Subject**

---

## Class-Subject Assignments

Assign a subject to a specific class so it appears in timetables and exam schedules.

Navigate to `/class-subjects`.

### Assign a Subject

1. Click **Assign Subject**
2. Select the **Class** and the **Subject** to assign
3. Click **Assign Subject**

> Each class-subject combination must be unique. The system prevents duplicate assignments.

---

## Curriculum

A Curriculum entry links a subject to an academic year, defining what is taught in which year.

Navigate to `/curriculums`.

### Add Curriculum

1. Click **Add Curriculum**
2. Select the **Subject** and the **Academic Year**
3. Click **Create Curriculum**

---

## Textbooks

Associate textbooks with subjects for reference in lesson planning and student resources.

Navigate to `/textbooks`.

### Add a Textbook

1. Click **Add Textbook**
2. Fill in:
   - **Subject** — select the related subject
   - **Title** — e.g. `Documentation Textbook`
   - **Author** — e.g. `Doc Author`
   - **Publisher** — e.g. `Doc Press`
   - **Edition** — e.g. `1st Edition`
   - **ISBN** — e.g. `978-000000`
3. Click **Add Textbook**

---

## Teacher-Subject Mappings

Specify which teachers are qualified and assigned to teach which subjects.

Navigate to `/teacher-subject-mappings`.

### Assign a Teacher

1. Click **Assign Teacher**
2. Fill in:
   - **Teacher** — select the staff member
   - **Subject** — select the subject they will teach
   - **Class** — select the class they teach it in
3. Click **Save**

---

## Recommended Setup Order

1. **Subjects** — create the subject catalogue
2. **Class-Subject Assignments** — link subjects to classes
3. **Curriculum** — bind subjects to academic years
4. **Textbooks** — add learning resources
5. **Teacher-Subject Mappings** — assign teachers
