# Attendance Management

Track and manage **student attendance, teacher attendance, leave requests, and school holidays** from a centralized dashboard.

Attendance Management helps schools monitor daily attendance, approve leave requests, and maintain holiday calendars.

---

## Features

- Daily Student Attendance
- Daily Teacher Attendance
- Student Leave Requests
- Teacher Leave Requests
- Holiday Calendar Management
- Attendance Filtering
- Leave Approval Workflow

---

# Attendance Dashboard

The **Attendance Overview Dashboard** gives administrators a quick summary of attendance statistics.

You can view:

- Students Present Today
- Teachers Present Today
- Pending Leave Requests
- Holiday Statistics
