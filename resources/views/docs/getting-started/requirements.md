# System Requirements

Before installing Vidra, ensure your server meets the following requirements.

## Minimum Requirements

| Requirement | Version |
|-------------|---------|
| PHP | 8.2+ |
| Composer | Latest Version |
| Node.js | 18+ |
| NPM | 9+ |
| Database | MySQL 8+ / PostgreSQL 14+ |
| Web Server | Apache / Nginx |
| RAM | Minimum 2 GB |
| Storage | Minimum 5 GB Free Space |

## Required PHP Extensions

Make sure the following PHP extensions are enabled:

- BCMath
- Ctype
- Fileinfo
- JSON
- Mbstring
- OpenSSL
- PDO
- Tokenizer
- XML
- cURL
- ZIP
- GD
- Intl

## Recommended Server Configuration

For better performance in production:

- **RAM:** 4 GB or higher  
- **CPU:** Dual Core or better  
- **Storage:** SSD recommended  
- **Web Server:** Nginx (recommended for scalability)

## Supported Platforms

Vidra can be deployed on:

- ✅ Ubuntu / Debian
- ✅ CentOS / RHEL
- ✅ Windows Server
- ✅ Shared Hosting *(with Composer & PHP support)*
- ✅ VPS & Dedicated Servers
- ✅ Docker Environment
- ✅ Cloud Platforms *(AWS, GCP, Azure, DigitalOcean)*

## Browser Compatibility

Vidra works smoothly on modern browsers:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari
